# 我家猫 · 真猫互动站

一只真实存在的金渐层英短。站里出现的每一只猫都是她的实拍照片，没有一张是画出来的；
衣裳、零食、家务道具同样来自实拍图。所有东西都是真的能点的：换装会真的穿在她身上，
表情包会真的导出一张 PNG，小游戏是真能玩输的。

移动端优先（390 px 起调），纯静态，无需构建，直接丢到 GitHub Pages 根目录就能跑。

## 页面（13 个）

| 页面 | 里面是真的什么 |
|---|---|
| `index.html` | 首页：会呼吸的真猫 + 今日四件事（进度从真实行为里读）+ 各入口封面 |
| `pet.html` | 我家猫：6 个表情 = 6 张原片，分区能摸（头/背/爪子/尾巴各有不同反应），档案、亲密计数 |
| `dressup.html` | 换装室：帽子/衣服/围巾三个真图槽位，再点一次就是脱下，可随机、可收藏、可导出 PNG |
| `meme.html` | 表情包制造机：真照片 + 上下文案 + 贴纸 + 字号/旋转，导出 PNG 或存进相册 |
| `gallery.html` | 生活相册：21 张站内原片 + 本机上传的照片，分类/搜索/写备注/下载/删除 |
| `games.html` | 游戏大厅：六款，显示最高分和局数 |
| `settings.html` | 我的：音效/动画/触感开关（立刻生效）、成绩、存储占用、导出 JSON、清空、还缺什么 |

## 六款小游戏（`game/` 目录）

| 游戏 | 玩法 | 结算依据 |
|---|---|---|
| `game/jump.html` 蓄力跳家具 | 按住蓄力、松手起跳，落进缝隙摔一次，三条命 | 跳出去的总距离 + 完美落点连击 |
| `game/laser.html` 追红点 | 手指按住红点满 0.5 秒才算追上，会加速/瞬移/分裂 | 60 秒内追上次数 |
| `game/hide.html` 猫在哪里 | 听喵声偏哪边、翻找有限次数，五关 | 五关全过的用时与翻错次数 |
| `game/sneak.html` 偷吃木头人 | 按住前进，吸尘器冲进过道时动一下就抓，松手有惯性 | 60 秒偷吃口数，被抓三次结束 |
| `game/whack.html` 敲地鼠·零食版 | 九宫格冒真零食和真道具，点错扣分断连击 | 30 秒得分 |
| `game/meow.html` 猫语翻译机 | 人话按字数和声调确定性地翻成喵语并真的发声，反向还有猜意题 | 自由玩 + 海报导出 |

游戏清单只有一份数据源 `js/games.js`：大厅、首页推荐、每款游戏页的标题和结算文案都从它取，
所以列表里不可能出现点进去 404 的死按钮。

## 本地跑起来

```
cd /d D:\cat\game
python -m http.server 8011
```

浏览器打开 `http://127.0.0.1:8011/`。直接双击 `index.html` 也能玩（数据存在浏览器 localStorage 里），
但画布导出 PNG 在 `file://` 下可能被浏览器拦住，导出类功能请用 http 预览。

## 部署到 GitHub Pages

站点根目录就是仓库根目录：Settings → Pages → `Deploy from a branch` / `main` / `root`，不需要 Actions。
资源路径全部是相对路径，仓库里也没有 `#`、空格或非 ASCII 文件名，所以不需要 `.nojekyll`。
推送后 CDN 生效一般要等 30～60 秒。

## 目录结构

```
index.html  pet.html  dressup.html  meme.html  gallery.html  games.html  settings.html
game/            六个游戏页，只有一个 canvas + 一行 script
js/core.js       存储、音效、震动机、导航外壳、toast/sheet、下载
js/cat.js        真猫抠图的舞台盒：呼吸、挤压、倾斜、跳动、分区命中
js/wardrobe.js   六件真图衣裳的锚点与绘制
js/game.js       游戏外壳：舞台缩放、计时、连击、结算封面、暂停
js/games.js      六款游戏的唯一清单
js/content.js    原片、文案、道具名、素材路径的统一出口
js/icons.js      内联 SVG 图标（不是图标字体，也没有图片）
js/p/<页>.js     每个功能页自己的逻辑
js/g/<游戏>.js   每款游戏自己的逻辑
css/app.css      全站唯一样式表
assets/          实拍素材（见下）
```

素材路径统一从 `js/content.js` 和 `CAT.asset()` 出，页面里不写死绝对域名，
所以换目录、换仓库名都不用改代码。任何一个素材缺失时会画出带「素材缺失」字样的虚线占位，
不会静默显示浏览器裂图。

## 数据存在哪

没有后端、没有数据库，全部在浏览器 localStorage 的一个命名空间 `meicat:` 下：
`settings` 偏好、`records` 各游戏最高分、`stats` 积分与次数、`wear` 当前装扮、`fits` 收藏的搭配、
`album` 本机上传的照片和表情包、`daylog` 今天的计数、`dayclaim` 今日任务领取标记、
`notes` 站内原片的备注覆盖。

所以：换设备或清缓存就会没。设置页明写了这一点，并给「导出 JSON」——导出的是一个文件，不是同步。
站内 21 张原片本身删不掉，能改的只有备注。

## 这一版没做的事

- 不会眨眼、不会张嘴、不会摇尾巴——缺上面 1/2/3 三张分件，界面上也没有放对应的假按钮。
- 换装室第四个槽位（背包）是锁着的说明卡。
- 照片只存在本机，没有云。
- 全站能动的素材只有正脸坐姿这一张抠图，所以横向跑跳、侧身、背影这类玩法暂时上不了；
  现在的六个游戏都是绕着这一张做的形变（倾斜、挤压、跳动、缩放）。
